# How to Choose Running Shoes for Beginners

Choosing your first running shoes is easier than it looks. The right pair fits well, feels comfortable from the first step and suits the surfaces you run on.

## Start with fit

Running shoes should leave about a thumb's width between your longest toe and the end of the shoe. Try running shoes on in the afternoon, when feet are slightly larger, and wear the socks you run in. A good fit matters more than any feature.

## Cushioning and drop

Cushioning is a matter of comfort. Beginners often like moderate cushioning, which protects the legs as they get used to running. The drop is the height difference between heel and toe; most beginners do well with a mid drop of 6 to 10 millimetres.

## Road or trail

Road running shoes are lighter and smoother underfoot. Trail running shoes have deeper grip and tougher uppers for mud and rocks. If you run on both, start with road running shoes and add a trail pair later.

## Where to buy

A specialist running shop can watch you run and suggest running shoes that match your stride. Many shops let you try running shoes on a treadmill, and some offer a trial period so you can return a pair that doesn't feel right.
